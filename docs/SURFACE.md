# Toolbar panel surface brief

## Job

Answer three questions instantly: Is FocusTube active? What did it filter? How can I change it?

## Composition

- Masthead with green status mark and editorial wordmark
- Session result strip: kept and hidden counts
- Active/pause switch presented as a direct control, not a settings maze
- Strictness slider with plain-language consequence
- Worker connection state and settings link in footer

## States

- Active: signal green, live counts, filtering copy
- Paused: warm warning treatment; all cards restored immediately
- Setup needed: endpoint warning and direct settings action
- Worker unavailable: previously classified cards use cache; new uncertain cards remain hidden

## Responsive target

Fixed browser action panel, 360px wide. No mobile variant.
